## Featured project

**[PricePulse](https://github.com/HoangMNguyen/pricepulse)** · [live site](https://pricepulse.hoangmnguyen.com) — a serverless price-history pipeline for IKEA and UNIQLO US. EventBridge-scheduled AWS Lambda jobs land raw catalog JSON in S3; an S3-triggered loader upserts idempotently into partitioned PostgreSQL (Neon); a FastAPI app on Lambda serves deals, price history, and watch alerts. Terraform-managed infrastructure, 126 pytest tests, GitHub Actions CI/CD with OIDC deploys. Live and running daily since Sep 2026.
